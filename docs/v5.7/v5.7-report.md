**Decided (can be changed):** group codes `R`, `MY`, `TA` (IDs have at most two letters; `R` is also what the German
file uses for this Russian book). Drawer names in English like most books: Russian, Burmese, Tamil; the web app shows
Русский, မြန်မာ, தமிழ். Colours not used by another book: dark blue, dark green, blue grey (pink was too close to
French). Placeholder icons `r.png`, `my.png`, `ta.png`.

**How:** one script for this file format, `ProvisionLanguageFile.groovy`, with a settings table per language; Gradle
`runRussian`, `runBurmese`, `runTamil`. Each task resets the database first (`importSql`), so run the three in one call:
`./gradlew :databaseProvisioner:runRussian :databaseProvisioner:runBurmese :databaseProvisioner:runTamil :sqlite:exportSql`.
Only a bare number starts a stanza, so an end-note listing "1. Куплеты 1-8 и 26" stays in the note.

**Fixes made to the files** (tell the brother):
- **BUR-365-alt was typed in Zawgyi** (the old Myanmar font encoding; it shows as broken letters on a modern phone).
  Converted to Unicode with ICU's `Zawgyi-my` transform; it now spells words like the other 705 hymns. A Burmese reader
  should still look at it.
- **BUR-576** ended with text copied from a web page ("Verses: 1 … 7", "Home | Top | Prev | Next"): removed.
- **Burmese: 32 words** had the asat (်) typed before the dot below (့). Put in the standard order (Unicode NFC), the one
  keyboards type, so search finds them. They look the same.
- **38 Russian words had Latin letters** that look like Russian ones (Latin "c" for "с", "o" for "о", "e" for "е",
  "B" for "В"; e.g. "Cлава", "cпас", and the word "с" itself). Search does not find such words. Replaced with Russian letters.
- **16 Russian hymns numbered their choruses as stanzas** (1, 2, 2, 3, 3, 4 where the English hymn is 1, chorus, 2,
  chorus, 3, chorus): R185, R210, R212, R300, R309, R361, R363, R388, R431, R433, R434, R450, R509, R516, R595, R597.
  Changed to `Coro:` where the English hymn has its chorus (only where the two matched block for block).
- **BUR-140** had two stanzas numbered 1 (the English hymn has 1, 2): the second is now 2.

**Checked:** no duplicate hymn numbers; every Related hymn exists in the app; database integrity ok; no existing hymn
changed except for the new links (1,006 English/New Songs/Be Filled hymns now list their R/MY/TA translations).
Emulator: the "Also in" chips show Russian, Burmese and Tamil; Burmese (stacked letters) and Tamil display correctly
with the phone's own fonts; drawer and icons fine. Web app tests 58/58 (new: a Tamil word is found and highlighted
whole), editor tests 13/13, Android unit tests pass.

**Web app and iPhone html search (fixed):** the search text kept only letters and digits, which drops the vowel signs
of Tamil and Burmese ("மாட்சி" became "ம ட ச"). Now letters, marks and digits are kept, in `tools/web/build.py`,
`tools/web/src/db.js` (and the highlighter in `app.js`) and `tools/ios/template.html`. The Android app searches with SQL
`LIKE` on the stored text, so it was not affected.

**To check with a tester:** the Android app's search ignores case only for A–Z (SQLite `LIKE`), as for Greek today, so
"бог" may not find "Бог". Ask a Russian tester whether that matters.
